# Proyecto Nova Stella
### __Estado:__ Desarrollo

__Descripción__: Nova Stella se basa en un proyecto de catalogo de animes, pero en este caso, es uno de novelas escritas principalmente por mi, con el objetivo de compartir las historias de los diversos personajes diseñados y actuados en los diversos videojuegos en los que se ha estado presente.

## __Stack utilizado__
- Docker
- Node (version 20)

## __Pasos de instalación__

1) Preparar el entorno de desarrollo. __Como recomendación puede usarse WSL o Docker Desktop.__

>No es obligatorio si desea utilizar herramientas instaladas en su equipo local

2) Una vez preparado el entorno, posicionarse en la carpeta raiz y hacer uso del docker-compose.yml proporcionado

3) Una vez levantado el entorno, acceder al contenedor app. __El objetivo es el de utilizar los comandos entregados por node, por ejemplo, "npm run dev" o "npm run build"__

4) Hacer uso del comando "npm run install", principalmente para instalar las depedencias utilizadas actualmente en el proyecto
